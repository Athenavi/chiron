# 截图与演示素材

README 首屏要回答三个问题：**它长什么样、我能用它做什么、多快能跑起来**。
文字只能答后两个，所以这里的素材是首屏转化的主要来源。

## 需要的图（按优先级）

| 文件 | 内容 | 为什么是它 |
|---|---|---|
| `screenshot-chat.png` | 一次完整的 Agent 运行：左侧会话列表，中间对话流，右侧/内联可见**思考过程与工具调用**逐步展开 | 这是产品与"聊天框套壳"的分水岭；静态截图就能看出区别 |
| `screenshot-trace.png` | 同一运行的轨迹视图：每步工具、耗时、token 用量 | 证明"过程可见"不是文案 |
| `screenshot-settings.png` | 后台「服务提供商」或「系统设置」页 | 证明它是可运营的多租户系统，不是 demo |
| `demo.gif` | 30 秒内：新建会话 → 提问 → 工具调用 → 知识库检索 → 回答 | GitHub 首屏唯一的"动"元素，转化率最高 |

## 规格

- 截图：宽 **1280–1600px**，PNG，深色主题统一（与产品默认一致），不要带浏览器边框和书签栏。
- GIF：宽 **≤ 1000px**，时长 **≤ 30s**，帧率 10–12fps，**体积 ≤ 8MB**（GitHub 对大于 10MB 的 GIF 会只显示首帧）。
  推荐先录屏再用 `ffmpeg` 压：`ffmpeg -i in.mp4 -vf "fps=12,scale=1000:-1" -loop 0 demo.gif`。
- 每张图 ≤ 500KB，超过请用 `pngquant` / `oxipng` 压一遍。

## 命名与引用

- 全部放在本目录，文件名用上表的名字（不要用 `1.png`、`屏幕截图 2026-11-04.png`）。
- 图片入库后，在 README 首屏标题下方插入引用：

```html
<p align="center">
  <img src="docs/images/screenshot-chat.png" alt="Chiron 对话界面：过程可见的 Agent 运行" width="900">
</p>
```

文件未入库前**不要**写进 README —— GitHub 会显示破图。

## 录制纪律（重要）

截图/录屏会**永久留存并被到处转载**，所以录制前：

- 用**全新库**起一套体验栈：`python scripts/demo_up.py --fresh-secrets`，不要用有真实数据的库；
- 演示账号用 `demo@example.com` 这类明显虚构的值，**不要**出现真实客户名、真实 API key、真实邮箱；
- 模型密钥用明显是示例的串（或直接打码），录完**撤销该 key**；
- 界面语言与 README 主体一致（中文），避免首屏图文不同语。
