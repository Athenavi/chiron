## 0. 这份分析的定位

- **可比性前提**：DSH 是**本地单租户 harness**，Chiron 是**多租户 SaaS** ⇒ **只有「同一层」才可比**：
  agent 循环 / 子 agent / 事件契约 / 执行隔离 / 可审计性。**交付形态与 UI 不可比**，不列入差距。
- **判据纪律**（与 `vendor/规划.md` §3.5 一致）：**「超越」= 对外可核实的行为**，不是「有对应模块」。
  每条切口落地时必须给出：**可复现命令 + 期望输出 + 反例**（未做时会怎样）。
- **北极星**：超越 DSH。
